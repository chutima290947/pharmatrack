# PharmaTrack

ระบบปฏิทินติดตามการจ่ายยาและการนัดหมายผู้ป่วย สำหรับเภสัชกรและบุคลากรทางการแพทย์

## คุณสมบัติของระบบ

- แสดงปฏิทินการจ่ายยารายเดือน
- ติดตามผู้ป่วยตามวันนัด
- จัดการสถานะการจ่ายยา
- บันทึกประวัติการจ่ายยา
- ค้นหาข้อมูลผู้ป่วย
- Dashboard สรุปข้อมูลการจ่ายยา
- รองรับการใช้งานผ่านเว็บเบราว์เซอร์

## เทคโนโลยีที่ใช้

- React
- Vite
- Tailwind CSS
- JavaScript
- LocalStorage
